# HANDAYA — Portal Acadêmico

Projeto inicial de um portal acadêmico pessoal, desenvolvido em HTML, CSS e JavaScript para publicação no GitHub Pages.

## Arquivos principais

- `index.html`: página inicial.
- `disciplinas.html`: índice de disciplinas.
- `publicacoes.html`: livros e publicações.
- `computacao.html`: ferramentas e aplicações computacionais.
- `recursos.html`: recursos educacionais.
- `sobre.html`: apresentação acadêmica.
- `css/styles.css`: identidade visual e layout responsivo.
- `js/site.js`: cabeçalho, menu e rodapé compartilhados.
- `assets/`: favicon e futuras imagens.

## Publicar no GitHub Pages

1. Crie um repositório novo no GitHub. Para um endereço `https://SEU-USUARIO.github.io`, o nome deve ser `SEU-USUARIO.github.io`.
2. Envie todos os arquivos e pastas deste projeto para a raiz do repositório.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`, depois salve.
6. Aguarde a publicação e acesse o endereço indicado pelo GitHub.

Também é possível usar outro nome de repositório; nesse caso, o endereço normalmente será `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Antes de divulgar

- Confira todos os links.
- Substitua os textos provisórios e as capas ilustrativas pelas informações e imagens definitivas.
- Acrescente os links reais dos livros e materiais.
- Teste em celular e computador.

## Observação

O projeto não copia automaticamente o conteúdo do Google Sites. Ele cria uma nova estrutura visual e de navegação. A migração dos materiais será feita em uma etapa posterior, conferindo cada link e arquivo para evitar perdas.
